# MoniToro — interface épurée

Un seul logo dans l’en-tête. Les mentions « à deux », « ensemble », « duo » et « partenaire » ont été retirées des textes de l’interface. Cette mise à jour ne change pas les comptes, les droits d’accès, les tables ni les données.

Décompresser le ZIP puis charger tous les fichiers à la racine du dépôt GitHub et valider Commit changes. Attendre le succès du déploiement Pages dans Actions, puis recharger Safari.

Conserver config.js existant : il est exclu du ZIP de mise à jour. config.example.js est uniquement un modèle pour une première installation. Ne pas relancer les fichiers SQL pour cette mise à jour. Ne pas effacer les données du navigateur.
